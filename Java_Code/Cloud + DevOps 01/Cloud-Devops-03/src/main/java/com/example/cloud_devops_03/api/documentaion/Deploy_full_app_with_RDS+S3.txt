STEP 5 — Deploy Backend Code

SSH into server:

ssh -i key.pem ubuntu@SERVER_IP

Install:

sudo apt update
sudo apt install nodejs npm nginx git

Clone app:

git clone YOUR_REPO
cd app
npm install

Add environment variables:

DATABASE_URL=
AWS_ACCESS_KEY_ID=
AWS_SECRET_ACCESS_KEY=
S3_BUCKET=
JWT_SECRET=

Run:

npm start

Production:
Use PM2.

npm install -g pm2
pm2 start server.js
pm2 save


STEP 6 — Connect Backend to RDS

Inside backend config:

const db = new Pool({
 connectionString: process.env.DATABASE_URL
})

Test:

npm run migrate

Check:

Tables created
Backend can read/write
Common Issue

RDS Security Group must allow EC2 access.

Add inbound rule:

PostgreSQL 5432
Source = EC2 security group

STEP 7 — Connect Backend to S3

Install SDK:

npm install @aws-sdk/client-s3

Example upload:

const s3 = new S3Client({
 region: "ap-south-1"
})

Upload:

await s3.send(new PutObjectCommand({
 Bucket: process.env.S3_BUCKET,
 Key: fileName,
 Body: fileBuffer
}))

Save URL into database.
