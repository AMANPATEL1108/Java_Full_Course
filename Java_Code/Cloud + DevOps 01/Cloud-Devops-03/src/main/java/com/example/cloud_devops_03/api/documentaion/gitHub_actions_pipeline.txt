1. What is GitHub Actions?

GitHub Actions Documentation

GitHub Actions is GitHub’s built-in CI/CD system.

CI = Continuous Integration
Automatically test/build code after changes
CD = Continuous Delivery/Deployment
Automatically deploy app to server/cloud
2. Why Spring Boot Developers Use It

For Java/Spring Boot projects, GitHub Actions can:

✅ Build Maven/Gradle projects
✅ Run unit tests
✅ Check code quality
✅ Generate JAR/WAR files
✅ Build Docker images
✅ Deploy to AWS/Render/Railway/Kubernetes
✅ Run on every push automatically

3. Big Picture Architecture
Developer pushes code
        ↓
GitHub Repository
        ↓
GitHub Actions Workflow starts
        ↓
Runner machine created (Ubuntu VM)
        ↓
Steps execute:
   - Checkout code

   - Build project

   - Deploy

7. Basic Pipeline Example

Create:

# .github/workflows/ci.yml

name: Spring Boot CI

on:
  push:
    branches:
      - main

jobs:
  build:

    runs-on: ubuntu-latest

    steps:

      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Setup Java
        uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: 17

      - name: Build with Maven
        run: mvn clean install

9. Steps

Each step executes sequentially.

Checkout Code
uses: actions/checkout@v4

Downloads your repository into runner machine.

Without this:
❌ no code available

Setup Java
uses: actions/setup-java@v4

Installs Java.

with:
  distribution: temurin
  java-version: 17

Sets Java 17.

Maven Build
run: mvn clean install

Runs Maven command.

Equivalent local command:

mvn clean install

15. Real Industry Pipeline

Production-grade example:

name: CI/CD Pipeline

on:
  push:
    branches:
      - main

jobs:

  build:

    runs-on: ubuntu-latest

    steps:

      - uses: actions/checkout@v4

      - uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: 17

      - name: Cache Maven Dependencies
        uses: actions/cache@v4
        with:
          path: ~/.m2
          key: maven-cache-${{ hashFiles('pom.xml') }}

      - name: Build
        run: mvn clean package

      - name: Run Tests
        run: mvn test

      - name: Upload Artifact
        uses: actions/upload-artifact@v4
        with:
          name: app-jar
          path: target/*.jar

31. Example Matrix Pipeline
jobs:
  build:

    runs-on: ubuntu-latest

    strategy:
      matrix:
        java: [17, 21]

    steps:

      - uses: actions/checkout@v4

      - uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: ${{ matrix.java }}

      - run: mvn test
