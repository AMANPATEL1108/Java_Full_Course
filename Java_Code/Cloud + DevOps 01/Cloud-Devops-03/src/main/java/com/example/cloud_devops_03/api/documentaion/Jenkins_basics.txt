Jenkins Basics for Java Spring Boot

Jenkins is an automation server mainly used for CI/CD (Continuous Integration / Continuous Deployment).

With a Spring Boot project, Jenkins can:

Pull code from GitHub/GitLab
Build your project using Maven or Gradle
Run tests
Create JAR files
Deploy the application automatically
1. What is Jenkins?

Jenkins automates software development tasks.

Example workflow:

Developer pushes code → Jenkins detects changes →
Builds Spring Boot app → Runs tests →
Deploys application
2. Why Use Jenkins in Spring Boot?

Benefits:

Automatic builds
Automatic testing
Faster deployments
Reduced manual work
Detect bugs early

8. Jenkins Pipeline for Spring Boot

Best practice is using a Jenkinsfile.

Create file in project root:

pipeline {
    agent any

    tools {
        maven 'Maven3'
    }

    stages {

        stage('Clone') {
            steps {
                git 'https://github.com/your-repo/demo.git'
            }
        }

        stage('Build') {
            steps {
                sh 'mvn clean install'
            }
        }

        stage('Test') {
            steps {
                sh 'mvn test'
            }
        }

        stage('Package') {
            steps {
                sh 'mvn package'
            }
        }

        stage('Run') {
            steps {
                sh 'java -jar target/demo.jar &'
            }
        }
    }
}

14. Jenkinsfile Advanced Example
pipeline {
    agent any

    environment {
        APP_NAME = "demo"
    }

    stages {

        stage('Build') {
            steps {
                sh 'mvn clean package'
            }
        }

        stage('Test') {
            steps {
                sh 'mvn test'
            }
        }

        stage('Deploy') {
            steps {
                sh '''
                docker build -t demo .
                docker run -d -p 8081:8080 demo
                '''
            }
        }
    }
}
