STEP 1 — WRITE & BUILD THE SPRING BOOT APPLICATION

This is where developers write code and create the application artifact (.jar).

1. Create Spring Boot Project

Use:

Spring Initializr
Maven or Gradle
Java 17+
Dependencies:
Spring Web
Spring Data JPA
MySQL Driver
2. Project Structure
src/
 └── main/
      ├── java/
      └── resources/
pom.xml
3. Build Tool (Maven)

pom.xml

<project>
    <modelVersion>4.0.0</modelVersion>

    <groupId>com.example</groupId>
    <artifactId>demo</artifactId>
    <version>1.0</version>

    <dependencies>

        <!-- Spring Boot -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-web</artifactId>
        </dependency>

    </dependencies>

    <build>
        <plugins>

            <!-- Create executable jar -->
            <plugin>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-maven-plugin</artifactId>
            </plugin>

        </plugins>
    </build>
</project>
4. Build the Application

Command:

mvn clean install

What happens:

Command	Meaning
clean	removes old build
compile	compiles Java code
test	runs test cases
package	creates jar
install	installs into local Maven repo

Generated file:

target/demo-1.0.jar

Run app:

java -jar target/demo-1.0.jar


STEP 2 — TESTING PIPELINE

Before deployment, the pipeline checks whether the app works correctly.

This is the Quality Gate.

Types of Testing
Type	Purpose
Unit Test	test single class
Integration Test	test DB/API
API Test	test endpoints
Security Test	vulnerability scan
Example Unit Test
@SpringBootTest
class DemoApplicationTests {

    @Test
    void contextLoads() {
    }
}

Run tests:

mvn test
Code Quality Tools

Common tools:

Tool	Purpose

STEP 3 — CI/CD PIPELINE AUTOMATION

Now automation starts.

This is the heart of DevOps.

What is CI/CD?
Term	Meaning
CI	Continuous Integration
CD	Continuous Delivery/Deployment
Popular CI/CD Tools
Tool	Usage
Jenkins	automation
GitHub Actions	GitHub CI
GitLab CI/CD	DevOps pipeline
Docker	containerization
Kubernetes	deployment
Example Jenkins Pipeline

Jenkinsfile

pipeline {
    agent any

    stages {

        stage('Build') {
            steps {
                sh 'mvn clean install'
            }
        }

        stage('Test') {
            steps {
                sh 'mvn test'
            }
        }

        stage('Package') {
            steps {
                sh 'docker build -t springboot-app .'
            }
        }

        stage('Deploy') {
            steps {
                sh 'docker run -p 8080:8080 springboot-app'
            }
        }
    }
}
Dockerize Spring Boot App
Dockerfile
FROM openjdk:17

COPY target/demo.jar demo.jar

ENTRYPOINT ["java","-jar","/demo.jar"]

Build Docker image:

docker build -t demo-app .

Run container:

docker run -p 8080:8080 demo-app
